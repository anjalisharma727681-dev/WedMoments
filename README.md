💍 WedMoments – Wedding Creator Booking App

WedMoments is an Android application designed to help users discover wedding photographers and creators, explore their packages, book services, manage wedding bookings, and track payments from one place.

The app provides a simple and user-friendly experience for planning wedding photography and creator services.

⸻

📱 About the App

Planning a wedding involves finding the right photographer, videographer, and content creator.

WedMoments makes this process easier by allowing users to:

* Discover wedding creators
* View creator profiles
* Explore wedding packages
* Select a suitable package
* Book a creator
* Manage bookings
* Track payment information
* View wedding details

⸻

✨ Features

🔐 Authentication

* Splash Screen
* Login
* Sign Up
* Forgot Password
* Reset Password
* Google Login support

🏠 Home Screen

* User information
* Wedding date
* Upcoming booking
* Featured creators
* Search creators
* Photography category
* Videography category
* Reels category
* Pre-Wedding category

👤 Creator Profile

Users can explore creator information including:

* Creator name
* Profile
* Experience
* Rating
* Portfolio
* Instagram
* Photos
* Videos
* Reviews

📦 Wedding Packages

Three different packages are available:

Basic Package – ₹15,000

* Photography
* 2 Reels
* 4 Hours coverage

Standard Package – ₹30,000

* Photography
* 4 Reels
* Wedding Video
* 8 Hours coverage

Premium Package – ₹50,000

* Photography
* 6 Reels
* Full Wedding Video
* 12 Hours coverage

📅 Booking System

Users can enter:

* Wedding Date
* Venue
* Selected Package
* Number of Events
* Special Requirements

After entering the details, users can confirm their booking.

📋 My Bookings

Users can view and manage their wedding bookings.

Booking status includes:

* Pending
* Confirmed
* Completed
* Cancelled

💳 Payment

Payment section displays:

* Package Price
* Advance Payment
* Remaining Amount
* Payment Status

💒 My Wedding

Users can view important wedding information including:

* Wedding Date
* Wedding Countdown
* Venue
* Events
* Selected Creator
* Booking Status

🖼️ Wedding Gallery

Gallery categories include:

* Wedding Ceremony
* Bride & Groom
* Wedding Decoration
* Mehendi
* Haldi
* Reception

⭐ Reviews

Users can:

* Give ratings
* Write reviews
* View previous reviews

👩 Profile

Profile section includes:

* Name
* Email
* Phone Number

* Edit Profile
* My Bookings
* Logout

🛠️ Tech Stack

* Language: Kotlin
* UI: Jetpack Compose
* Design: Material 3
* IDE: Android Studio
* Platform: Android
* Backend: Firebase
* Authentication: Firebase Authentication
* Database: Cloud Firestore
* Storage: Firebase Storage
* Version Control: Git & GitHub
